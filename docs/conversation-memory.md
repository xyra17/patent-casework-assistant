# 对话与记忆

在任务结果中选择“对话与记忆”，可继续追问、指定参考轮次、切换话题或回看保存的回答。来源与筛选口径可从每轮回答下方打开。

例如：先列出客户甲的案件，再问“这些案件中只看林澄负责的”，或“把负责人改成周行，保持其他条件”。新话题会重置案件范围；历史快照保留当时的回答和来源，不代表当前数据。

| 记忆层 | 保存内容 |
| --- | --- |
| 工作上下文 | 本次执行的工具结果、来源和校验反馈 |
| 会话记忆 | 当前目标、筛选条件、已展示案件和逐轮快照 |
| 项目长期规则 | 用户确认后保存的稳定约定及其来源 |

会话记忆不跨会话自动共享。长期规则用于匹配范围内的任务，可以编辑、停用；本次明确要求优先。拟稿不会自动保存，追问也不会扩大本次数据源权限。
