# 代理部门共享盘模拟资料

这是当前主业务场景。所有办理资料独立编写，均使用模拟客户、IPR、代理师和案号；未由用户真实案卷改写，也不表示真实委托或专利申请。技术正文是用于检查机制检索的短篇夹具，不是成熟申请文件。

- 编号规则：所编号使用 `DEMO-2026-014`（演示前缀／年份／序号），客户案号独立使用 `DEMO-CLIENT-018`；两者均为模拟标识，不使用真实案件式编号。
- `source/`：年份／所编号.客户案号／每案Excel、立案.doc、交底或申请文件、会议表、交局确认。立案.doc实际为OOXML，用于检验扩展名误命名。
- `expected.json`：独立gold、人员领域、会议参与人、月报边界和反例。
- `semantic.yaml`：只读投影字段口径与首页模板。
